음성·인지검사 채점 검증실 진단 아님

음성을 텍스트로 변환해 확인하고, 검사자가 실제 검사에서 채점한 결과를 공개된 공식 점수 규칙으로 계산하는 실험실입니다. 한국어 GPCOG 질문 원문을 복제하지 않으며 정식 검사 시행을 대신하지 않습니다.

음성 AI 상담 웹통화는 Retell 테스트 ↗에서 따로 체험할 수 있습니다. Retell과 이 채점 실험실의 데이터는 아직 자동 연결되지 않았습니다.

① 음성 측정값 가져오기

기존 Evidence의 JSON에는 음성 원본이 없으므로 텍스트 전사할 수 없습니다. 음향 지표만 불러옵니다.

불러온 측정 기록 없음

가상 데이터로 채점 흐름 확인

이 기능은 가상 음성 재생·전사 테스트가 아니라 공식 채점 규칙 계산을 확인합니다. 아래 ③~⑥에도 결과가 자동 반영됩니다.

② 음성 → 텍스트 (Whisper)

기본 Whisper tiny는 가볍지만 한국어 전사 품질이 부족할 수 있습니다. 더 큰 사전학습 모델을 선택할 수 있으며 정확도 향상을 보장하지 않습니다. 음성 원본은 기기에서 처리합니다.

원음을 재생해 녹음 품질을 확인한 뒤 전사 결과와 비교하세요. 미리 듣기 역시 브라우저 내부 기능입니다.

오디오 입력 대기 중 · 음성 원본은 서버로 업로드하지 않습니다.

전사 결과는 채점 담당자가 확인해야 하며 자동으로 정답·오답을 확정하지 않습니다.

③ 문장 읽기 · 발음 차이 후보 검토

아래 문장을 똑같이 읽어 녹음하고, 위의 선택된 음성 전사를 누른 뒤 여기서 비교하세요. 인식 결과에서 어긋난 글자와 위치(문자 순서)를 보여줍니다. 실제 음소 발음 채점이나 의학적 평가는 아닙니다.

읽기 기준 문장 · 고정 과제
오늘은 날씨가 맑아서 집 근처 공원을 천천히 걸었습니다.
음성을 먼저 녹음하거나 파일로 불러온 뒤 전사하세요. 직접 수정한 텍스트는 원본 ASR과 구분됩니다.

문자 차이율은 ASR 모델의 인식 결과를 원문과 비교한 텍스트 지표입니다. 발음 정확도 점수가 아니며, 음소별 실제 오류인지 검증하지 않았습니다. 같은 문장의 반복 변화는 동일한 기기·조건과 사람의 확인이 필요합니다.

④ GPCOG 환자 평가 9개 항목

정식 검사자가 공식 검사지로 시행한 후 항목별 정오를 입력합니다. 그림·시계 그리기 등은 오디오 전사만으로 채점할 수 없습니다.

⑤ 보호자 면담 6개 항목

환자 5~8점일 때 필요합니다. 공식 FAQ 기준: '예(변화 발생)'는 0점, '아니요·모름·해당 없음'은 각각 1점. 미입력은 점수가 아닙니다.

⑥ 전사와 목표 답변 대조 보조

검사자가 정식 과제의 목표 답변 요소를 직접 입력하면, 전사 텍스트에 문자 일치가 있는지만 확인합니다. 표현이 달라도 정답일 수 있어 자동 점수로 반영하지 않습니다.

아직 비교하지 않았습니다.

⑦ 채점 결과와 근거

환자 9개 항목의 채점이 완료되면 공식 점수 규칙을 계산합니다.
정확성·사용권한 안내

공개된 GPCOG 채점 규칙을 확인하는 시뮬레이터입니다. 공식 검사 문항, 시행 절차, 해석 역량을 제공하지 않습니다. GPCOG 웹사이트는 개인 비상업적 이용조건을 명시합니다. 상용 서비스에 정식 검사로 도입하려면 도구 소유자의 허락과 전문 검증이 필요합니다.
