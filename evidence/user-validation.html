어떤 기록을 신뢰할 수 있나

자료마다 확인 단계와 해석 범위를 표시합니다.

① 출처·참여 조건

수집일, 조사 유형, 참여자 구분, 표본수·응답률의 분모, 실제 사용 여부, 질문지 버전과 원본 참조번호를 확인합니다.

② 개인정보·공개 동의

공개 동의가 있는 익명·집계 자료만 표시합니다. 이름·연락처·정확한 위치·건강 원자료와 자유응답 원본은 공개 저장소에 넣지 않습니다.

③ 주장 가능한 범위

사용 의향 ≠ 이용 실적, 만족도 ≠ 제품 효능, 의료진 의견 ≠ 임상 검증, 예시 응답 ≠ 사용자 근거. 미확인은 그대로 표시합니다.

자료 등록 기준: 실제 참여·실사용 여부 및 수집 경로 확인 → 중복·예시 제외 → 공개·동의 범위 확인 → 출처 확인 → 집계 또는 비식별 요약 게시. 새로운 결과가 없을 때에는 ‘미등록’으로 유지합니다.
