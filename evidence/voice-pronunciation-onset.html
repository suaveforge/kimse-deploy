첫 단어가 낮게 나오는 이유 확인

같은 문장을 두 번 읽어 녹음 첫부분을 비교합니다. 이후 동일 음원에 0.5초 무음을 붙여 Azure 점수가 달라지는지 확인할 수 있습니다.

이 검사는 발음 능력이나 질환을 판정하지 않습니다. 원본 음성은 분석 요청을 누르기 전까지 서버에 전송하지 않습니다.

검사 문장은 녹음 시작이 확인된 뒤 화면에 나타납니다.

1. 녹음 시점 비교

A · 즉시 읽기

녹음 시작 확인과 동시에 문장이 보입니다.

B · 기다렸다 읽기

녹음 시작 확인 후 1.5초가 지나면 문장이 보입니다.

녹음 방식을 선택해 주세요
오늘은 날씨가 맑아서 집 근처 공원을 천천히 걸었습니다.
녹음이 실제 시작되면 마이크 막대가 반응합니다. 둘 다 같은 문장을 읽으세요.
기존 테스트와 별도 녹음입니다.

2. 녹음 앞부분 확인

B · 1.5초 후 읽기

파형은 첫 2.5초의 실제 PCM 음압을 표시합니다. 시작 위치 후보는 단순 음량 기준이므로 음성 시작 정답은 아닙니다. A와 B는 서로 다른 발화라 점수 비교만으로 녹음 결함을 확정할 수 없습니다.

3. 동일 음원 Azure 비교

선택한 한 녹음을 원본과 앞에 0.5초 무음이 추가된 복사본으로 각각 분석합니다. 원본 발화의 표본은 바꾸지 않습니다.

비교할 녹음을 선택해 주세요.

베타 분석 서버 상태를 확인 중입니다.

확인 기준

A에서만 첫부분이 잘리고 B에서는 정상이라면 녹음 시작 구간을 추가 검증합니다. 같은 음원을 앞에 무음만 붙였는데 첫 단어 점수나 정렬이 크게 달라지면 Azure 시작 경계에 민감할 수 있습니다. 두 현상 모두 단 한 번의 검사로 원인을 확정하지 않습니다.
